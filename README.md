# ICT-LAB-HTML-Assignment-1
ICT Lab HTML Assignment

Task 1: Create a Personal Webpage
Question: Design a personal webpage that includes the following:
 A title with your name.
 An introductory paragraph about yourself.
 A section with at least three hobbies listed in an unordered list.
 An image representing one of your hobbies.
 Ensure the webpage is well-structured using appropriate HTML tags.

Task 2: Build a Navigation Menu
Question: Create a simple navigation menu using HTML and CSS with the following
requirements:
 The menu should contain links to &quot;Home,&quot; &quot;About,&quot; &quot;Services,&quot; and &quot;Contact.&quot;
 Style the menu to display horizontally.
 Add hover effects to the links (e.g., change color or underline).
 Ensure the menu is responsive and adapts to different screen sizes.

Task 3: Design a Product Card
Question: Create a product card layout with the following elements:
 An image of the product.
 A product title.
 A short description.
 A price tag.
 A &quot;Buy Now&quot; button.
 Use CSS to style the card with borders, padding, and hover effects.

Task 4: Create a Simple Login Form
Question: Develop a login form that includes:
 Input fields for username and password.
 A &quot;Submit&quot; button.
 A &quot;Forgot Password?&quot; link.
 Use CSS to style the form, including input field styles, button styles, and layout
centering.

Task 5: Create a Feedback Form
Question: Build a feedback form that contains:
 Input fields for name, email, and feedback message.
 A rating system using radio buttons (e.g., 1 to 5 stars).
 A &quot;Submit&quot; button.
 Style the form with CSS to improve usability and appearance.

Task 6: Create a Basic Table
Question: Design a basic HTML table to display a list of students with the following columns:
 Name
 Age
 Grade
 Email

Task 7: Create a Multi-Section Landing Page
Question: Design a landing page that includes multiple sections:
 A hero section with a call-to-action button.
 An &quot;About Us&quot; section with text and an image.
 A &quot;Services&quot; section with a list of services offered.
 A &quot;Contact&quot; section with a simple contact form.
Instructions:
 Use HTML to structure the page.
 Style the sections with CSS, ensuring a cohesive design across the page.
 Implement responsive design principles for mobile compatibility.
